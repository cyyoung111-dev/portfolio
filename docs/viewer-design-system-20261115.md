# 포트폴리오 뷰어 통합 디자인 시스템 (2026-11-15)

## 목표와 범위
- 웹·모바일에서 같은 역할의 버튼·탭·필터·카드가 같은 높이, 모서리 반경, 간격, 선택 상태를 사용합니다.
- 금융 계산, GAS, 원천 API, 거래원장, Snapshot, NAV, 저장·동기화 및 버튼 이벤트는 변경하지 않습니다.
- 기존 테마(라이트/다크/사용자 정의)와 글꼴·UI 크기 조절을 유지하기 위해 CSS의 `--s1`, `--s2`, `--border`, `--text`, `--muted`, `--amber`, `--radius-control`, `--radius-card`, `--type-caption`, `--control-height-*`를 재사용합니다.

## UI 규칙
| 구성요소 | 통일 규칙 | 역할에 따른 예외 |
|---|---|---|
| 상단 업데이트·현재가·툴바 | 데스크톱 62×54px, 같은 라벨 높이·아이콘 17px·반경 | 업데이트는 앰버, 읽기 전용 현재가는 블루, 삭제·초기화는 레드 |
| PC/모바일 탭 | 공통 테두리·높이·선택 시 앰버 배경과 하단선 | 드래그/탭 정렬과 스크롤 기능 유지 |
| 계좌·종류·손익 필터 | 공통 소형 버튼·간격·선택 배경 | 거래 매수·매도 선택은 기존 녹색/적색 우선 |
| 설정·에디터·액션 | 공통 버튼 최소 높이·반경·비활성 및 키보드 포커스 | 실거래, 금융 입력 및 승인 로직 불변 |
| 자산·손익·섹터·거래 카드 | `--radius-card`, 동일한 부드러운 그림자·테두리 | 상승/하락/주의 색상과 데이터 숫자 유지 |
| 날짜 입력·조회 상태 | 공통 테두리·반경·최소 높이 | 기준일·실시간 판정 변경 없음 |

## 반응형
- 769px 이상: 주행동 버튼과 보조 버튼 높이 54px, 탭 높이 54px.
- 481~768px: 날짜 + 주요 버튼 2개를 한 행에 배치하고, 상태 메시지를 다음 행 전체에 표시. 보조 버튼/탭은 가로 스크롤.
- 301~480px: 날짜 전체 폭, 업데이트·현재가 동일한 2열 버튼(46px 높이), 보조 버튼/탭은 가로 스크롤.
- 300px 이하 또는 매우 큰 접근성 확대: 주요 버튼을 1열로 배치해 텍스트를 자르지 않음.
- 키보드 `:focus-visible` 강조, `disabled` 및 `aria-busy` 구분, `prefers-reduced-motion` 기존 전역 정책 유지.

## 적용 및 검증
- 뷰어 CSS: `src/web/styles/ui-unified.css?v=20261115-1` (기존 스타일시트 중 가장 마지막).
- 서비스워커 등록/캐시: `20261115-2`, CSS도 PWA 사전 캐시.
- `scripts/check-web-structure.mjs`: HTML 로딩·프리캐시 버전 및 순서 일치.
- `scripts/check-typography.mjs`: 공통 버튼/탭/선택/비활성/모바일/테마 토큰 계약.
- PR 웹·필수 CI 및 병합 후 Pages 배포는 실제로 확인합니다. 모바일 기기 시각 결과, 브라우저 글꼴 크기별 터치 편의성, 실측 초기 페인트는 별도 기기 확인 전까지 **검증 완료라고 주장하지 않습니다.**

## 배포 후 수용 점검
1. PC: 라이트/다크 테마에서 업데이트·현재가·보조 툴바의 높이/글자 가독성 비교.
2. 모바일: 360~430px 너비에서 2개 주요 버튼의 같은 크기, 탭/툴바 가로 스크롤, 카드 숫자 잘림 여부.
3. 손익 그래프: 기준일, MDD, 비교지수 토글, 확대 후 필터 클릭 가능 여부.
4. 접근성: 키보드 포커스, 비활성 버튼, 자동조회 진행 상태와 테마 전환.

## 2026-11-15 2차 점검 — 레거시 CSS 충돌 정리와 태블릿·테마 수정

- 기존 `responsive.css`의 480px 버튼 40px·탭 40px·날짜 2열·300px 예외 등 **새 통합 디자인과 중복되는 옛 규격을 삭제**했습니다. 기존 데이터 진단칩, 상태 레이아웃, 보조 기능 스크롤, 관리 컴포넌트 스타일은 유지합니다.
- 601~768px에서도 상단 영역을 1열 그리드로 구성해 날짜·업데이트 버튼을 모두 표시합니다. 보조 툴바는 **그 아래 자체 가로 스크롤**을 사용하며 화면 전체가 가로 밀리지 않도록 변경했습니다.
- 손익 이력 날짜·월 선택기의 `color-scheme:dark` 고정을 사용자 라이트/다크 테마에 맞춰 덮어쓰고, 라이트 모드의 달력 아이콘은 강제 반전을 중지했습니다.
- 현재가 상태 문구는 사용자 설정 `--type-caption`을 사용해 기존 모바일의 별도 `.65rem` 값에 따른 작은 표시를 방지합니다.
- 디자인 버전 `ui-unified.css?v=20261115-2` 및 PWA 캐시·등록 `20261115-3`. 기존 금융·환율·조회·거래·Snapshot·GAS 처리는 미변경입니다.
- 실제 실물 PC/모바일에서의 화면 검수는 별도이며, 필수 회귀검사는 스타일 소유권, 태블릿 레이아웃, 라이트/다크 달력, 모바일 2열, 300px 접근성 확대를 확인합니다.

- 레거시 모바일 스타일 자체도 `responsive.css?v=20261115-1`로 버전업하고 SW precache를 동기화했습니다. `check-web-structure`가 새·구 모바일 CSS 모두의 HTML·SW 일치 여부를 필수 검증합니다.
