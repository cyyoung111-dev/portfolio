# 텔레그램 장전 요약 발송

한국 거래일 07:30 KST에 TFL 야간선물 참고값을 수집해 날짜별 artifact로 저장하고 07:40에 Telegram 요약 발송을 시도한다. 08:00에 추가 예약을 실행하며, 발송 전 확보한 당일 claim이 없을 때만 다시 시도한다. claim은 발송 성공이 아니라 전송 가능성을 뜻한다. claim 후 실패 또는 응답 불명은 중복 방지를 위해 자동 재발송하지 않는다. GitHub 예약의 지연·누락 가능성이 있어 정시 도착을 보장하지 않는다. 실제 수집이 07:30 전이거나 08:00 이후인 경우 보관하지 않고, 발송이 08:10 이후이면 메시지를 보내지 않는다.

발송 작업은 같은 거래일 07:30~08:00에 정상 완료된 main 예약 수집의 TFL artifact만 사용한다. 날짜·계약·06:00 표시·실제 수집 시각을 검증하며 누락·실패·불일치 시 해당 수치를 미확보로 표시한다. TFL은 마지막 수신 참고값이며 KRX 공식 확정 종가가 아니다. 07:30 기존 공식 MORNING 스냅샷 자동 발행은 중지하고 수동 진단 경로 및 다른 시각의 기존 처리만 유지한다.

시장 요약을 준비한 뒤 날짜별 `telegram-morning-claim-YYYY-MM-DD` artifact를 먼저 저장하고 저장 성공 후에만 Telegram에 요청한다. 동일 날짜 claim은 중복 발송을 차단하며 14일 보관한다. claim은 발송 성공 증거가 아니므로 `SENT` 로그를 별도로 확인한다. 업로드 후 취소 또는 전송 불확실 시 재발송하지 않으며 재실행(attempt>1)도 차단한다.

수동 Run workflow는 명시적인 연결 시험 메시지만 전송한다. 실제 예약 발송과 수신은 다음 거래일에 검증해야 한다.
