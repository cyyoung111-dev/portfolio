# 텔레그램 장전 요약 발송

한국 거래일 08:30·08:40·08:50 KST에 GitHub 예약 실행 기회를 둡니다. GitHub 예약의 지연·누락 가능성은 남으므로 정시 도착 보장은 아닙니다. 모든 기회가 09:00 이후 시작되면 장전 메시지를 보내지 않습니다.

동일 concurrency 그룹에서 직렬 실행하며, 시장 지표를 준비한 뒤 해당 KST 날짜의 `telegram-morning-claim-YYYY-MM-DD` artifact를 먼저 저장합니다. 저장 성공 후에만 Telegram에 요청합니다. 후속 예약은 같은 날짜의 기록을 발견하면 발송하지 않습니다. 기록은 14일 보관하며 임의로 삭제하지 않습니다.

기록은 발송 시도를 예약했다는 뜻이며 전송 성공 증거가 아닙니다. 업로드 후 취소되거나 전송 응답이 유실되면 해당 날짜는 자동 재발송하지 않습니다. 중복 발송 방지를 우선하는 제한이며 `SENT` 로그를 별도로 확인합니다. Artifact 조회·저장 실패 시 발송하지 않습니다. 워크플로 재실행(attempt>1)도 자동 발송하지 않습니다.

수동 Run workflow는 명시적인 연결 시험 메시지만 전송합니다. 실제 시장 본문을 장중에 뒤늦게 보내는 기능은 없습니다. 정상 자동 발송 검증은 다음 거래일 schedule 실행과 전송 결과로 확인해야 합니다.
