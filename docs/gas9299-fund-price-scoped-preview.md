# 9.299 독립 펀드 평가 가격이력 범위 저장 (소스 후보)

- 2026-11-18 CLOSE: 주식 39행, PRICE/Snapshot 11/18, NAV 완료일 11/17, 지연된 독립 펀드 평가 3회 시작 뒤 완료 미확인. 9.298 preflight run 44332677739에서 TIMEOUT_SUSPECTED 및 TIMEOUT 확인. 내부 시간 초과 단계는 미확정.
- 실제 9.285 기준 소스와 9.298 조합 경로를 확인했다. 자동 펀드 평가(_refreshFundValuations)는 32일 검사, 락 전 읽은 가격 배열을 락 내부에서 전체 재저장한다. 다른 쓰기 이후 오래된 비대상 행을 다시 쓰는 위험과 불필요한 I/O가 존재한다.
- 고정된 9.298 후보에서 자동 평가(maxSnapshotWrites)만 변경: 기존 ScriptLock 내에서 현재 행을 재인덱싱하고 대표행 선택·MANUAL 보존을 유지하며 변경 행만 연속 범위로 저장 및 readback. 원래 백업/실패 표시/원본 revision 경로 유지. 추가행도 readback. 수동 전체 저장 로직 및 펀드 기준가격·Snapshot·거래원장·트리거·NH 진단 동작 변경 없음(버전 표시 제외).
- 수정은 실제 시간 초과의 단일 원인을 확정하거나 복구를 인증하는 것이 아니다. 자동 평가의 전체 가격이력 쓰기 병목을 제거하는 별도 소스 후보. 기존 9.298 승인 소스 해시 및 deploy allowlist는 일절 변경하지 않는다. 9.299의 실제 배포·추가 호환 검증은 별도 승인 절차가 필요하며 9.298의 배포 실패를 우회하지 않는다.
