# PC·모바일 업데이트 속도 점검: 기기별 즉시 진단

## 2026-11-11 변경
- 외부연동 > PC·모바일 조회시간 진단에 **이 기기 최근 조회시간** 버튼을 추가합니다.
- 기존 `window.__PF_LOOKUP_TIMES`의 최근 60건 메모리 계측에서 단계별 마지막 성공/실패 소요시간을 표시합니다.
- 전체 업데이트/서버 데이터 복원/가격 재조회/화면 재계산, GAS bootstrap/가격 및 가격이력 요청, 현재가 폴링을 구분합니다.
- 이 로컬 버튼은 인증, 동의, 서버 쓰기 및 네트워크 요청 없이 즉시 작동합니다. 페이지 새로고침 시 기록은 사라집니다.
- 별도 독립 성능 수집기(PC·모바일 7일 비교)의 운영 허용 단계 목록은 변경하지 않았습니다. 현재 설치된 원격 수집기가 허용하지 않는 새로운 단계명을 전송하면 전체 묶음이 거부될 수 있기 때문입니다.

## 사용
1. 웹 또는 모바일에서 전체 **업데이트**를 누릅니다.
2. 외부연동 > PC·모바일 조회시간 자동 진단 > **이 기기 최근 조회시간**을 누릅니다.
3. PC와 모바일의 복원·가격·렌더링 소요시간을 비교합니다.
4. 동일 기기에서 최소 3회씩 확인하고 중앙값을 비교합니다. 표시 수치는 가장 최근 값이므로 통계 검증은 별도입니다.

금융 GAS·가격이력·Snapshot·거래원장·NAV 변경 없음. 차후 중앙 수집기의 단계 목록 확장은 #860 종료 후 독립 배포 및 운영 검증을 거쳐야 합니다.
