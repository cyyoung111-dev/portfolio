# 업데이트 속도 2차 개선 — 휴장일 범위 조회 및 단계별 계측 (2026-11-11)

기존 전체 업데이트 및 최초 자동 조회는 당일 가격이 없으면 이전 5일을 최대 5회 직렬로 조회했습니다. 이 경로를 첫 실패 후 `getPriceHistory(from=T-5,to=T-1)` 한 번으로 대체했습니다. GAS 서버에는 쓰지 않습니다.

- 각 보유 종목은 범위 내 실제 가격 기준일 `sourceDate`가 가장 최신인 값을 택합니다. 미래일·범위 밖·날짜 미확인 값은 제외하고, 다른 기준일 가격을 당일로 승격하지 않습니다.
- 정확한 과거 지정일은 기존 당일 조회 및 수동가격 우선 규칙을 유지합니다.
- 코드 없는 펀드의 기존 90일 NAV 조회는 독립 병렬로 유지합니다.
- 요청 병합 키에 범위 시작일을 넣어 정확 일자와 기간 조회를 구분합니다.
- 전체 업데이트 소요시간을 데이터 복원/가격 재조회/화면 재계산 세 단계로 계측합니다.
- `check-holiday-window-fallback`은 실제 프로덕션 가격조회 함수를 VM에서 실행해 결측·펀드·날짜·휴장일 계약을 검사합니다.

운영 금융 GAS/거래원장·Snapshot·가격이력 변경은 없으며, 서버 측 변경 버전/증분 조회 설계는 #860 종료 후 별도 안전 검토가 필요합니다. 성능 개선의 실제 초 단위 수치는 PC·모바일 측정 전까지 추정하지 않습니다.
