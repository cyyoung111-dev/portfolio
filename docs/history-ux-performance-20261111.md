# 손익 그래프·업데이트 1차 UX/속도 개선 명세 (2026-11-11)

## 목표
- PC/모바일에서 현재 손익, 기간수익률, 최대 MDD 날짜를 우선 확인
- 원천/NAV 이월, 지수별 상세 원천, 유지보수는 접어서 보고 필요할 때 열기
- 전체 업데이트의 동일한 포트폴리오 전체 렌더링 중복을 제거하여 불필요한 CPU/DOM 작업 축소

## 반영 범위
1. 원자료 기준 계산 요약만 기본 표시하고 펀드·종가 이월 사례는 details로 노출
2. 비교지수 선택 및 지수별 원천·MDD 카드 접기. 기존 선택/원본 조회/지수 계산은 변경하지 않음
3. 현금흐름 보정 수익률 MDD의 `troughDate`(최대 낙폭일), `peakDate`(직전 고점일), -MDD% 표시. 해당 날짜의 실제 평가금액은 참고용이며 MDD 계산의 분모로 사용하지 않음
4. 최고/최저 **평가금액** 카드는 그대로 유지, 별도로 최대 낙폭 시점을 표시하여 두 지표를 혼동하지 않도록 함
5. 상단 조회의 NH/KRX/왕복/GAS 제공자 세부정보는 펼치기 영역으로 이동
6. GAS 원격 강제복원 후 첫 전체 화면 재계산을 제거하고 가격 성공/실패/빈 보유 각각 **한 번** 렌더링

## 정합성 계약
- 거래 338건·보유 39종, NAV·가격·Snapshot 원본의 읽기/쓰기 경로 변경 없음
- getBootstrap 강제복원, 미전송 거래 journal, CAS 및 종목 마스터 복구, getPrices(persist=1) 유지
- MDD는 검증된 일별 Snapshot과 거래별 순현금흐름 제거 수익률 지수, 주간/월간 차트에서도 기간 중 일별 최대낙폭 보존
- P&L 절대 최저 평가금액과 MDD 저점 날짜는 다를 수 있음
- 모든 원천/경고 세부 내용은 접근 가능한 <details>에 보존

## 측정/후속
- 성능 개선율은 아직 실측 전. 클라이언트 `load.full-update`, `network.getBootstrap`, `network.getPrices` 계측으로 모바일/PC 중앙값·p95 비교
- GAS getPrices 90초 한도/저장 작업 자체 최적화는 #860 완료 후 별도 서버 검토. 이번 PR에서 금융 GAS 재배포 금지.
- 검증: check-history-modes, 새로운 MDD/UX/렌더 단계 정적 회귀, 기존 웹/Quality CI
