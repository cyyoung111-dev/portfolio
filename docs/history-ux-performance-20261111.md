# 손익 그래프·업데이트 1차 UX/속도 개선 명세 (2026-11-11)

## 목표
- PC/모바일에서 현재 손익, 기간수익률, 최대 MDD 날짜를 우선 확인
- 원천/NAV 이월, 지수별 상세 원천, 유지보수는 접어서 보고 필요할 때 열기
- 전체 업데이트의 동일한 포트폴리오 전체 렌더링 중복을 제거하여 불필요한 CPU/DOM 작업 축소

## 반영 범위
1. 원자료 기준 계산 요약만 기본 표시하고 펀드·종가 이월 사례는 details로 노출
2. 비교지수 선택 및 지수별 원천·MDD 카드 접기. 기존 선택/원본 조회/지수 계산은 변경하지 않음
3. 현금흐름 보정 수익률 MDD의 `troughDate`(최대 낙폭일), `peakDate`(직전 고점일), -MDD% 표시. 해당 날짜의 실제 평가금액은 참고용이며 MDD 계산의 분모로 사용하지 않음
4. 최고/최저 **평가금액** 카드는 그대로 유지, 별도로 최대 낙폭 시점을 표시하여 두 지표를 혼동하지 않도록 함
5. 상단 조회의 NH/KRX/왕복/GAS 제공자 세부정보는 펼치기 영역으로 이동
6. GAS 원격 강제복원 후 첫 전체 화면 재계산을 제거하고 가격 성공/실패/빈 보유 각각 **한 번** 렌더링

## 정합성 계약
- 거래 338건·보유 39종, NAV·가격·Snapshot 원본의 읽기/쓰기 경로 변경 없음
- getBootstrap 강제복원, 미전송 거래 journal, CAS 및 종목 마스터 복구, getPrices(persist=1) 유지
- MDD는 검증된 일별 Snapshot과 거래별 순현금흐름 제거 수익률 지수, 주간/월간 차트에서도 기간 중 일별 최대낙폭 보존
- P&L 절대 최저 평가금액과 MDD 저점 날짜는 다를 수 있음
- 모든 원천/경고 세부 내용은 접근 가능한 <details>에 보존

## 측정/후속
- 성능 개선율은 아직 실측 전. 클라이언트 `load.full-update`, `network.getBootstrap`, `network.getPrices` 계측으로 모바일/PC 중앙값·p95 비교
- GAS getPrices 90초 한도/저장 작업 자체 최적화는 #860 완료 후 별도 서버 검토. 이번 PR에서 금융 GAS 재배포 금지.
- 검증: check-history-modes, 새로운 MDD/UX/렌더 단계 정적 회귀, 기존 웹/Quality CI

## 2026-11-11 compact follow-up
- 현금흐름 보정 MDD는 차트 아래 가로 요약 한 곳에서만 노출하고, 직전 고점일과 최악일 평가금액은 접기형 상세로 제공합니다.
- 최고/최저 평가금액은 모바일에서 2열 미니카드로 요약합니다. 각 카드의 매입원가·수익률은 필요할 때 펼칩니다.
- 그래프 아래의 반복적인 MDD 범례 수치를 제거했습니다. 벤치마크별 MDD는 비교지수 상세에서 계속 볼 수 있습니다.
- 스냅샷 표 렌더의 MDD 재계산을 제거했습니다. 기존 가격·손익·수익률·MDD 계산식과 금융 GAS·거래원장·NAV는 변경하지 않습니다.

## 모바일·PC 실화면 가독성 3차 개선 (2026-11-11)
- 모바일/PC의 실제 `손익 그래프`에서 차트 안과 아래에 겹치던 지수 범례를 한 곳(하단 반응형 칩)으로 합쳤습니다.
- 현재 손익/현금흐름 보정 수익률 KPI에 일관된 패딩·글자·색상 계층을 부여했습니다. MDD는 별도의 간결한 가로 요약이며 기존 최대 낙폭 계산은 변경하지 않습니다.
- 선택한 비교지수 6종은 데스크톱 3열 / 모바일 2열의 간결한 카드로 배치합니다. 기본은 `지수명, 기간수익률, MDD, 고점→저점일`이고 공신력 확인에 필요한 `조회값, 기준일, 데이터 원천`은 각 카드 `종가·원천`을 펼치면 확인할 수 있습니다.
- 증감률 색상은 기존 지수 구분 색상과 일치하며, CSS 반응형으로 화면 너비를 따라갑니다. 원천 결측, 세부값, MDD 산식 및 선택 필터 유지.
- 금융 GAS·가격원본·Snapshot·거래원장 원본 쓰기 0건. 실제 모바일 장치 시각 품질은 배포 후 재확인이 필요합니다.

## 2026-11-15 — 현재가 자동조회 동일가격 렌더 생략

- 60초마다 조회되는 `pollCurrentPrices()`에서 기존 `savedPrices`, 종목별 공식 기준일 표시, `lastUpdated`, 전역 환율을 원래의 조회값과 대조합니다. **기존 rows가 렌더되어 있고 모든 표시 입력이 동일할 때만** `refreshAll()` / `recomputeRows()` / `invalidateViewCache()`를 생략합니다.
- 공식 원천 요청과 연결 세대/복원 세대/선택 과거날짜/hidden 탭 방지, `persist:false`, 60초 주기, 거래원장·스냅샷 미저장 정책은 그대로 유지합니다. 조회가 성공했어도 데이터가 동일하면 `현재가 확인 · 변동 없음`으로 표시합니다.
- 가격이 같아도 기준일·환율이 변하거나 화면이 아직 처음 렌더되지 않았으면 기존처럼 평가액·손익·도넛·표를 갱신합니다. 설정 탭에서는 자동화 관리 패널을 다시 만들지 않습니다.
- 합성 UI 테스트는 동일가격 no-op, 날짜·FX 변경, 최초 렌더, 실제 가격 변경, 백그라운드·연결세대 차단, 네트워크 1회/중복합치기, 금융 저장 0을 확인합니다. 실제 모바일/PC 속도 개선율은 브라우저 계측 전까지 미확정입니다.
