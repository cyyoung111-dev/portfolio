# 고배당기업 배당소득 과세특례 — 1차 개발 (2026-11-18)

- 조특법 §104조의27: https://www.law.go.kr/lsLinkCommonInfo.do?lsJoLnkSeq=1022572951
- 시행령 §104조의24 및 국세청 신고 안내: https://www.nts.go.kr/nts/na/ntt/selectNttInfo.do?mi=2201&nttSn=1349597
- KIND 공식 대상 현황: https://kind.krx.co.kr/valueup/dividend.do?method=valueupHighDividendMain
- 2026~2029 지급분 참고 시나리오, 법정 누진세율 14/20/25/30%, 지방소득세 10% 가산. 단순 원천징수와 신고 후 시나리오 구분. 이후 기간에 영구 적용하지 않음.
- 공개 공시 근거와 종목코드·배당기준일·주당금액·지급연도 일치한 결산배당에 한해 신청 가정 합산 제외. 실제 지급 및 최종 과세자료 미검증. ETF/ISA/연금 제외 범위 기존대로, 일반계좌 ETF 과세표준 차이는 별도 확인.
- 삼성전자 보통/우선 2025 결산 공시 확인. SK 재공시 DART 원문은 502로 확인 실패하여 후보로 보류. 전체 KIND 목록은 해당 연도와 사업연도 차이 및 정정공시 유의. 자동 수집 엔드포인트는 미확보이며 이번 PR에 임의 추정 목록을 넣지 않음.
- 실제 이자소득/기타 금융소득 자동 연동 (현재 세션 내 가정 입력 가능), 비과세 감액배당, 종합세액(누진·비교과세·배당세액공제 등)과 완전한 자동 수집은 후속 작업. 미확인분 종합과세 합산 참고에서 차감하지 않음. 실제 신고·은행 입금과 분리.
- 공개 근거 레지스트리만 추가. 금융 기록·GAS 변경 없음.
