Portfolio GAS Deploy · 적용일 2026년 10월 26일

대상과 목적

본 방침은 개인 포트폴리오의 Apps Script 배포 보조 도구에 적용됩니다. 운영자는 프로젝트 소유자가 승인한 Google API 권한으로 Apps Script 소스·버전·배포 설정·실행 상태를 조회하고, 승인한 코드 변경과 배포를 수행합니다.

접근하는 정보

OAuth 인증에 필요한 토큰과 클라이언트 인증정보, Apps Script 프로젝트 코드 및 배포·실행 관련 메타데이터를 처리합니다. 접근 범위는 Google 동의 화면에서 승인한 권한에 따릅니다. 포트폴리오 앱에 연결한 금융 자료는 사용자가 지정한 Google Sheets 및 브라우저 저장소에서 별도로 관리됩니다.

저장과 보호

자동 배포에 사용하는 인증정보는 보호된 GitHub Actions 환경의 암호화된 Secrets에 보관하며 실행 과정에서 사용합니다. 로컬 인증을 수행한 경우 인증파일은 사용자의 기기에도 남을 수 있습니다. 운영 로그는 진단에 필요한 제한된 상태·건수 위주로 기록합니다. 인증정보·코드 원문·금융 원본을 이 공개 안내 페이지에 게시하지 않습니다.

외부 서비스와 이용 제한

인증과 프로젝트 작업에는 Google API, 자동 실행에는 GitHub Actions를 사용합니다. 각 서비스는 자체 개인정보처리방침과 보관 정책을 적용합니다. 이 도구는 Google 사용자 데이터를 판매하거나 광고 목적으로 제공하지 않으며 AI 모델의 학습 목적으로 사용하지 않습니다. 공개 문의에 비밀정보를 올리지 마세요.

보관과 삭제

인증정보는 연결을 유지하는 동안 보관합니다. 사용을 중단하려면 Google 계정에서 해당 앱의 접근 권한을 철회하고, GitHub의 관련 Secrets 및 기기의 인증파일을 삭제할 수 있습니다. Google에서 권한을 철회해도 이미 만들어진 프로젝트 코드·시트·배포·GitHub 실행 기록이 자동 삭제되지는 않습니다. 해당 자료는 각 서비스에서 별도로 관리합니다.
