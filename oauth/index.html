Portfolio GAS Deploy

개인 포트폴리오 도구의 Google Apps Script 코드와 웹앱 배포를 관리하는 개인용 자동화 프로젝트입니다. 프로젝트 소유자가 본인 Google 계정으로 승인한 범위에서 사용합니다.

기능과 Google API 사용 목적

  • Apps Script 프로젝트 소스와 기존 배포 상태 조회
  • 검토한 코드 저장, 버전 생성 및 웹앱 배포
  • 배포 결과와 자동화 실행 상태 확인

Google OAuth는 이 작업을 수행할 권한을 받는 용도로 사용합니다. 이 안내 페이지에서 Google 로그인을 시작하거나 인증정보를 입력받지는 않습니다.

포트폴리오 화면

포트폴리오 앱 열기 — 본인이 설정한 데이터 연결을 사용하는 화면입니다. 이 공개 소개 페이지에는 보유종목·수량·금액·계좌정보를 게시하지 않습니다.
