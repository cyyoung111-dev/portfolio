# 포트폴리오 성능 진단 — 기존 Google 계정의 독립 Apps Script

- Cloudflare/D1 계정 없음. **기존 금융 GAS 프로젝트도 수정하지 않습니다.**
- 별도의 Apps Script 프로젝트를 같은 Google 계정 안에 만들고, 그 스크립트의 `PropertiesService`만 사용합니다.
- Google Sheets/Drive/원장/보유종목/NH/Snapshot/Telegram API는 코드에 없습니다.
- 저장 데이터는 `기기 분류, 조회 단계, 밀리초, 성공 여부`만 사용합니다. 브라우저 기기별 동의는 기존 외부연동 화면에서 관리합니다.
- 7일 보존, 기기별 100 샘플/일, 1개 키당 7,600자 제한, 각 샘플 배치 최대 8건. 단말 식별자·종목/원장/인증정보 저장하지 않습니다.
- 비밀번호는 기존 GAS 인증값에서 파생된 SHA-256값으로 별도 검증합니다. 금융 GAS 원래 인증값은 **새 GAS로 전송하지 않습니다.** GitHub Actions 생성 스크립트에도 원본 토큰을 배포 코드에 넣지 않습니다.
- 관리 경로: `.github/workflows/provision-standalone-performance-gas-20261103.yml`. 메인 최초 병합 때 한 번만 보호된 Google OAuth로 신규 프로젝트를 만들고, 실제 게시 주소는 워크플로의 안전한 실행 결과에서 읽어 이후 웹 UI에 지정해야 합니다.
- API 생성·게시 권한 부족 / 새 프로젝트 최초 실행 인가 문제 발생 시 수집 가동이 되지 않습니다. 원 금융 GAS를 수정/삭제/차단하지 말고, 신규 프로젝트만 따로 검토합니다.
- 별도 Scripts project를 생성할 수 없으면 새 프로젝트 시도를 임의 반복하거나 v9.282 금융 writer gate를 우회하지 않습니다.
- 본 기능은 보조 진단이며 사용자의 PC·모바일 조회 측정 기록이 쌓이기 전에는 성능 개선 수치를 주장하지 않습니다.
